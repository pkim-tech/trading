# Heap

Pre-cache working area — ultra-short-term idea capture, a corollary to
`backlog_cache.md`. Meant for jotting quick "by the way" thoughts mid-session
without polluting the backlog cache with half-formed ideas. Entries here are
disposable: once an idea either gets built or is deliberately dropped, remove
it (or move it to `backlog_cache.md`/`deep_backlog.md` if it's real and still
open). Not committed to the permanent record the way `deep_backlog.md` is —
this is scratch space, not history.
